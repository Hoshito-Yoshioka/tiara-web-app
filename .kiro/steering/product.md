# Product Overview

函館の店舗「TIARA」の公式 Web アプリケーション。店舗情報・スタッフ情報・出勤スケジュール・料金を顧客に提供する公開サイトと、コンテンツを運用するための管理画面・スタッフポータルを一体で提供するフルスタックアプリ。本番サイトは https://tiara-hakodate.com/ で公開されている。

## Core Capabilities

- **公開サイト**: ホーム / 店舗紹介 / スタッフ一覧・詳細 / 出勤スケジュール / 料金 / アクセスの各ページを提供。SEO のため vite-ssg でプリレンダリング（SSG）済み
- **管理画面（`/admin`、要管理者認証）**: 店舗情報編集、スタッフ管理（作成・編集）、メニュー管理、プロフィール承認・シフト承認のレビューワークフロー
- **スタッフポータル（`/mypage`、要スタッフ認証）**: スタッフ本人によるプロフィール編集・シフト編集。編集内容は管理者の承認（レビュー）を経て公開される
- **画像アップロード**: スタッフのプロフィール画像等を Backend が保持し、BFF 経由で `/uploads` として配信

## Target Use Cases

- 来店を検討する顧客が、スタッフ・出勤予定・料金・アクセス情報を確認する
- 店舗管理者が、店舗情報・スタッフ・メニューを更新し、スタッフの申請（プロフィール/シフト）を承認する
- スタッフが、自分のプロフィールと出勤シフトをセルフサービスで申請する

## Value Proposition

- 顧客向けの公開情報と、スタッフ・管理者による更新ワークフロー（申請→承認→公開）を 1 つのアプリで完結
- SSG 化により公開ページは静的 HTML として高速配信され、検索エンジンにインデックスされる（管理画面・ポータルは noindex かつプリレンダリング対象外）
- 将来の機能拡張（予約システム等）を見据え、バックエンドはクリーンアーキテクチャで設計（docs/ADR.md 参照）
